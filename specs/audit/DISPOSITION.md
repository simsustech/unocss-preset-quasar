# Flagged-class dispositions

Generated from `node specs/audit/coverage-sweep.mjs`. The sweep flags every class
`quasar/dist/quasar.css` styles that this preset's sheet never emits — the classes
a Quasar consumer can write today that would render unstyled here.

**Every flagged class needs a row.** Dispositions:

| disposition      | meaning                                                                                              |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| `fix`            | a defect for this preset; the row names the commit that fixed it                                     |
| `allowlisted`    | the vocabulary script carries it with a rationale (scraper gaps, runtime-applied modifiers)          |
| `static-channel` | emitted through the preflight CSS text, not by a rule (classes UnoCSS's token pipeline cannot route) |
| `equivalent`     | dist's selector form is covered by an equivalent selector this sheet emits                           |
| `deferred`       | known, recorded, deliberately not fixed; the reason says what work it needs                          |

`static-channel` and `equivalent` extend the disposition vocabulary the plan
lists (`fix` / `allowlisted` / `deferred`), for two cases the
plan's labels cannot express: a class that is styled without becoming a rule
(this preset has a second emission channel), and a modifier class whose effect
is emitted through its parent's selector. Both are recorded rather than left
undispositioned, which is the point of the table.
