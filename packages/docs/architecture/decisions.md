# Decisions

The recorded design decisions behind the preset, one entry each. Full texts live in `docs/adr/` in the repository.

| #    | Decision                                                                                                                                                                | In one line                                                                                                                                                                                                                        |
| ---- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0001 | [Audit tooling contract](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0001-audit-tooling-contract.md)                                          | Three committed gates (vocabulary, dist-coverage, value-sweep) each fail unless every finding has a disposition row — "no new flags" is not a criterion, because it passes on pre-existing residue.                                |
| 0002 | [Reference quirks and the wind4 delegation rule](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0002-reference-quirks-and-wind4-delegation.md)   | `quasar/dist/quasar.css` is the arbiter for what Quasar means; MD3/MD2 specs are a cross-check; a class wind4 already emits identically is wind4's to emit.                                                                        |
| 0003 | [preset-mini over wind4](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0003-preset-mini-over-wind4.md)                                          | The nested engine is `preset-mini` — wind4's on-demand variables, base reset and bare `col-N` grid rule each broke Quasar rendering; consumers add wind4 themselves via `quasarWind4Options`.                                      |
| 0004 | [`--q-*` for our defaults](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0004-quasar-namespace-for-our-defaults.md)                             | Defaults this preset owns live in `--q-*`, never in the engine's `--un-*` namespace; engine names are read engine-first with a `--q-*` fallback, except the opacity quartet where the engines disagree on type.                    |
| 0005 | [App-extension CSS is opt-in and selector-keyed](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0005-opt-in-selector-keyed-app-extension-css.md) | Ported library CSS ships only when declared in `appExtensions`, as rules (not preflight text), keeping upstream selectors and re-namespacing only the tokens.                                                                      |
| 0006 | [Explicit, tree-shaken style configuration](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0006-explicit-and-tree-shaken-style-configuration.md) | `QuasarPreset()` throws without `styles`/`style`; the first entry is the baseline, the rest are switch blocks, and a style's own rules ship iff the style is listed.                                                               |
| 0007 | [One overlay layering scale](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0007-overlay-layering-scale.md)                                      | Every z-index in the preset belongs to one stated scale — in-flow drawer 1000, overlay drawer 1500, marginals 2000, menus/dialogs 6000, tooltip 9000, notify/loading 9499/9500 — so the app bar stays visible over an open drawer. |
| 0008 | [Style-independent policies are not style defects](https://github.com/simsustech/unocss-preset-quasar/blob/main/docs/adr/0008-style-independent-preset-policies.md)     | The generated palette, the 48 dp control floor and the screen breakpoints are shared by design; a divergence in them is recorded, not fixed.                                                                                       |

## Themes that recur

- **Evidence over inference.** Every engine choice, value and parity claim was measured by generating output side by side — not inferred from naming or documentation.
- **Inclusion is the switch.** What an app lists is what an app ships: styles, plugins, app extensions. Nothing is on by default that an app did not ask for.
- **One authority per value.** dist for Quasar's semantics, the spec for metrics, the palette generator for color, one layer scale for z-index. When two sources disagree, the disagreement is recorded rather than averaged.
